# Smart Task Manager

AI-powered task scheduling and management application.

## Overview

Smart Task Manager uses AI to understand user requests in natural language
and intelligently schedule tasks based on
the user's routine, availability and constraints.

## Key Features

- Natural-language task creation
- AI-powered task intent detection
- Intelligent task scheduling
- Calendar-based task management
- Drag-and-drop rescheduling
- AI task assistant
- Recurring routines
- User-specific task management
- Auth0 authentication
- MongoDB persistence
